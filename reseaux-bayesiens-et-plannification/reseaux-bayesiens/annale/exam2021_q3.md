# Exam 2021 — Correction détaillée de la Question 3 (Réseaux Bayésiens)

> **Énoncé (Q3) :** *Donnez les formules permettant d'obtenir des tables qui contiennent les probabilités conjointes pour tous les groupes de l'arbre de groupes. Détaillez les raisonnements pour les obtenir, en justifiant les indépendances entre variables, lorsque c'est nécessaire, n'effectuez aucun calcul.*

---

## Rappel du contexte (Questions 1 et 2)

### Graphe causal (Q1)
```
      N         R
     / \       /
    ▼   ▼     ▼
    D     L ◄─┘
    │     │
    ▼     ▼
    M     E
```
Arcs : `N → D`, `D → M`, `N → L`, `R → L`, `L → E`.

### Arbre de jonction & Initialisation (Q2)

- **Version 1 (4 groupes) :**
  ```
  [DM] ──(D)── [DN] ──(N)── [LNR] ──(L)── [EL]
  ```
  Initialisation :
  - $t_{LNR} = P(N) \times P(R) \times P(L \mid N, R)$
  - $t_{DN} = P(D \mid N)$
  - $t_{DM} = P(M \mid D)$
  - $t_{EL} = P(E \mid L)$
  - Séparateurs : $t_D = t_N = t_L = \mathbb{1}$

- **Version 2 (3 groupes) :**
  ```
  [DMN] ──(N)── [LNR] ──(L)── [EL]
  ```
  Initialisation :
  - $t_{LNR} = P(N) \times P(R) \times P(L \mid N, R)$
  - $t_{DMN} = P(M \mid D) \times P(D \mid N)$
  - $t_{EL} = P(E \mid L)$
  - Séparateurs : $t_N = t_L = \mathbb{1}$

---

## Résolution de la Question 3

### 1. Groupe `LNR` : contient déjà la probabilité conjointe $P(L, N, R)$

À l'initialisation, on a :
$$t_{LNR} = P(N) \times P(R) \times P(L \mid N, R)$$

Par la formule des probabilités composées (règle de la chaîne) :
$$P(L, N, R) = P(N) \times P(R \mid N) \times P(L \mid N, R)$$

**Justification de l'indépendance entre `N` et `R` :**
- La seule chaîne entre `N` et `R` est `N → L ← R`.
- C'est une **connexion convergente en `L`**.
- Comme on ne connaît aucune évidence sur `L` ni sur son descendant `E`, la chaîne est **bloquée** : `N` et `R` sont **d-séparées par $\emptyset$**, donc **indépendantes**.
- Par conséquent : $P(R \mid N) = P(R)$.

**Conclusion :**
$$t_{LNR} = P(N) \times P(R) \times P(L \mid N, R) = \mathbf{P(L, N, R)}$$

---

### 2. Groupe `EL` : envoi de message `LNR → EL` (séparateur `L`)

1. **Mise à jour du séparateur `L`** *(marginalisation de $t_{LNR}$ sur `N` et `R`)* :
   $$t'_L = \sum_{N, R} t_{LNR} = \sum_{N, R} P(L, N, R) = P(L)$$
2. **Mise à jour de la table du groupe `EL`** :
   $$t'_{EL} = \frac{t_{EL} \times t'_L}{t_L} = \frac{P(E \mid L) \times P(L)}{\mathbb{1}} = \mathbf{P(E, L)}$$

---

### 3. Partie gauche de l'arbre

#### Cas Version 1 : `[DM] ──(D)── [DN] ──(N)── [LNR]`

1. **Envoi de message `LNR → DN` (séparateur `N`) :**
   - Mise à jour du séparateur `N` *(marginalisation sur `L` et `R`)* :
     $$t'_N = \sum_{L, R} t_{LNR} = \sum_{L, R} P(L, N, R) = P(N)$$
   - Mise à jour de la table du groupe `DN` :
     $$t'_{DN} = \frac{t_{DN} \times t'_N}{t_N} = \frac{P(D \mid N) \times P(N)}{\mathbb{1}} = \mathbf{P(D, N)}$$

2. **Envoi de message `DN → DM` (séparateur `D`) :**
   *(Maintenant que `DN` contient la probabilité conjointe $P(D, N)$, on propage vers `DM`.)*
   - Mise à jour du séparateur `D` *(marginalisation sur `N`)* :
     $$t'_D = \sum_{N} t'_{DN} = \sum_{N} P(D, N) = P(D)$$
   - Mise à jour de la table du groupe `DM` :
     $$t'_{DM} = \frac{t_{DM} \times t'_D}{t_D} = \frac{P(M \mid D) \times P(D)}{\mathbb{1}} = \mathbf{P(D, M)}$$

---

#### Cas Version 2 : `[DMN] ──(N)── [LNR]`

1. **Envoi de message `LNR → DMN` (séparateur `N`) :**
   - Mise à jour du séparateur `N` *(marginalisation sur `L` et `R`)* :
     $$t'_N = \sum_{L, R} t_{LNR} = \sum_{L, R} P(L, N, R) = P(N)$$
   - Mise à jour de la table du groupe `DMN` :
     $$t'_{DMN} = \frac{t_{DMN} \times t'_N}{t_N} = \frac{P(M \mid D) \times P(D \mid N) \times P(N)}{\mathbb{1}} = P(N) \times P(D \mid N) \times P(M \mid D)$$

2. **Justification que $t'_{DMN} = P(D, M, N)$ :**
   - Par la règle de la chaîne :
     $$P(D, M, N) = P(N) \times P(D \mid N) \times P(M \mid D, N)$$
   - Dans le graphe, la chaîne `N → D → M` est une **connexion série en `D`**, donc `{D}` **d-sépare** `M` et `N`.
   - Par conséquent, `M` et `N` sont **indépendantes sachant `D`**, ce qui donne :
     $$P(M \mid D, N) = P(M \mid D)$$
   - D'où :
     $$t'_{DMN} = \mathbf{P(D, M, N)}$$
